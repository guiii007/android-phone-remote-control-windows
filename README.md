# 安卓手机远程控制 Windows · 掌上遥控

通过安卓手机浏览器控制 Windows 电脑。针对手机操作设计双手鼠标、中文文字编辑和系统键盘布局，支持使用 Tailscale 从手机流量连接电脑，无需自建公网服务器。

## 功能

- 右手拖动箭头旁的圆柄移动鼠标，左手点击左键、右键；按住左键并拖动圆柄可选中文字。
- 慢速滚轮、双击、完整画面、横屏显示与画面内按钮透明度。
- 使用手机自带输入法，本地选词、改字后“输入电脑”；提交后保留键盘。
- 删除、换行（Shift＋Enter）、发送（Enter），由电脑目标应用解释快捷键。
- 动态画面优先响应，静止后补高清；适合时使用无损 PNG。手机端可调锐化力度。
- 首次长密钥配对，之后同一浏览器用自己设置的四位密码解锁。
- 短断线自动恢复当前会话，不自动重发文字、点击或按键。
- Windows 启动面板自动准备已登录的 Tailscale；只有一个任务栏窗口。

安卓手机与 Windows 真机已完成试用，用户确认当前连接稳定性和画面清晰度满足使用需求；其他设备和网络仍需验证。这是个人远控原型，当前仅支持主屏幕、一个控制页面。

## 安装

需要 Windows、Node.js 22 或以上版本，以及电脑和安卓手机上的 Tailscale。电脑需保持已登录、桌面解锁、联网且不休眠。

1. 下载本仓库 ZIP 并解压，或使用 Git 克隆。
2. 在项目目录运行：

```powershell
npm ci --ignore-scripts
```

3. 两端 Tailscale 登录同一账号，完成设备连接。首次登录需要本人操作。
4. 双击 **启动手机远控.cmd**。首次会从源码构建图形启动入口，之后直接打开启动面板。
5. 查看启动面板提供的手机访问地址，以及手机 Tailscale 显示的 IPv4 地址。在管理员 PowerShell 中放行自己的手机：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/enable-external-access.ps1 -PhoneIP "替换为手机的TailscaleIPv4"
```

脚本自动读取电脑 Tailscale IPv4、Node.js 路径和所用端口，只允许指定手机访问该端口。安装路径或地址识别不正确时可显式传入 `-ComputerIP`、`-NodePath`、`-Port`。更换手机、修改端口或更换 Node.js 路径后，需要更新规则；旧规则可在 Windows 防火墙中移除。

## 手机怎么连接

1. 手机开启 Tailscale，使用流量或可联网的 Wi-Fi。
2. 打开**自己的启动面板显示的网址**，不要复制其他人的电脑地址。
3. 首次点击面板“复制连接密钥”，把自己的密钥输入手机页面，设置并确认自己的四位数字密码。
4. 以后在同一浏览器打开收藏的网址，只需输入四位密码。

每一份全新安装会在自己的电脑上随机生成独立的 256 位密钥，保存在 `.pairing-token`；重复启动保留原密钥。仓库不包含任何真实密钥、设备记录或个人网络配置。浏览器保存随机设备凭据，网页不会公开或持久保存电脑长密钥。清除浏览器数据、换浏览器或网址后需重新配对；忘记四位密码时可用自己的长密钥重新设置。

电脑使用时可最小化面板，关闭面板会停止由它启动的远控服务。Tailscale 后台保持运行，供其他项目继续使用。

## 地址、端口与安装路径

手机网址由电脑实际 Tailscale IPv4 和远控端口组成，默认端口为 **8789**。局域网地址可能随网络变化，Tailscale 地址也以本机实际状态为准。

如需改端口，把 `remote-settings.example.json` 复制为 `.remote-settings.json`，修改：

```json
{
  "port": 8899
}
```

重启远控，更新防火墙规则，并在手机收藏新网址。环境变量 `PORT` 优先于配置文件。

默认从 PATH 找 Node.js，从 Tailscale 标准安装目录或 PATH 找客户端。自定义安装位置时，在本机配置中增加 `nodePath`、`tailscalePath`，或设置 `NODE_PATH_EXE`、`TAILSCALE_EXE` 环境变量。Windows 路径在 JSON 中使用双反斜杠。这份本机配置被 Git 忽略，不会发布。

## 画面与连接

动态画面默认上限 1440 像素、JPEG 质量 70；慢链路改为 1080/60 或 960/55。静态补帧上限 2560 像素、质量 85，不放大超过原屏幕尺寸；PNG 不超过 JPEG 的 1.25 倍时优先 PNG。高清往返过慢后改用 1440/75 静态帧。同一张静态图片不重复上传，最多一帧在途，避免积压旧画面。

“选项”显示静态/动态档位和画面往返耗时，可调整清晰增强。增强不能恢复源图中已丢失的字形，较弱手机会自动回到原画。完整桌面缩到手机上时，字的物理大小也会变小。

短断线最多退避重试 5 次，当前会话的恢复凭据只留在网页内存，失联后最多 5 分钟有效。主动断开撤销凭据；刷新后重新输入四位密码。恢复会释放旧鼠标状态并请求新画面，不重发先前输入。Tailscale 直连失败时可能使用中继，网络本身的延迟和长期断网无法由网页消除。

## 演示和局域网

```powershell
npm run demo
```

电脑浏览器打开 `http://127.0.0.1:8787/`，自动连接虚拟电脑，不操作真实桌面。也可双击 `start-demo.cmd`。虚拟电脑使用独立演示密钥。

真实桌面局域网试用可运行 `start-phone-windows.cmd`，然后使用 `show-real-phone-address.cmd` 查看本机地址。校园网等公共 Wi-Fi 可能隔离设备，可改用手机热点验证。明文局域网入口仅用于可信网络测试，不能直接开放公网。

## 安全边界

- 四位密码必须与该浏览器的随机设备凭据一起校验；连续输错五次开始等待，逐步延长至十分钟，等待状态跨服务重启保留。
- 设备记录在 `.device-access.json`，包含加盐密码摘要、设备凭据摘要和错误等待状态，属于私有本机数据。
- 默认外网方案在 Tailscale 私有加密组网内使用 HTTP；不要把远控端口直接暴露公网，也不需要开启 Funnel。
- 不支持 UAC、锁屏、Windows 登录界面和更高权限窗口。识别到密码输入框时拒绝远控文字输入。
- SendInput 成功不等于目标应用正确接收；输入结果需要观察电脑画面。
- 无开机自启、远程唤醒、文件传输、多屏或原生安卓 App。保持电脑开机且不休眠。
